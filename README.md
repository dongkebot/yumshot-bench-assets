# yumshot-bench-assets

YumShot 竖版成片样片（35 张），供 `magazine-poster-gen` 测试集作为菜品照使用。
公开仓库只是为了让 Runware 能通过 `https://raw.githubusercontent.com/dongkebot/yumshot-bench-assets/main/samples/Sxx.jpg` 读取图片；风格库和 skill 本体在私有仓库里。

- `samples/S01.jpg` … `S35.jpg`：长边不超过 2048 px，JPEG 质量 90
- `index.json`：编号 → 原文件名、尺寸、sha256 前 16 位
